Step 1: Identify Your App ID and Environment
┌─────────────────────────────────────────────────────────────────────────┐
│ App ID: d39hijjwy5dz8q                                                  │
│ Environment: ecommerce-shopping-cart-20251221-043801                    │
│ Base Path: /amplify/d39hijjwy5dz8q/ecommerce-shopping-cart-20251221... │
└─────────────────────────────────────────────────────────────────────────┘

Step 2: Create SSM Parameter (AWS Console)
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Go to AWS Systems Manager > Parameter Store                         │
│ 2. Click "Create parameter"                                             │
│ 3. Enter name: /amplify/{APP_ID}/{ENV}/{PARAM_NAME}                     │
│ 4. Choose type: SecureString (sensitive) or String (non-sensitive)     │
│ 5. Choose KMS key: "My current account" (default)                      │
│ 6. Enter value                                                          │
│ 7. Click "Create parameter"                                             │
└─────────────────────────────────────────────────────────────────────────┘

Step 3: Use in Your Code
┌─────────────────────────────────────────────────────────────────────────┐
│ // For React apps, use REACT_APP_ prefix                               │
│ const apiKey = process.env.REACT_APP_API_KEY;                           │
│                                                                          │
│ // Amplify injects SSM values during build                             │
│ // Parameter: /amplify/{APP_ID}/{ENV}/API_KEY                           │
│ // Available as: process.env.REACT_APP_API_KEY                          │
└─────────────────────────────────────────────────────────────────────────┘

Step 4: Trigger New Build
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Push new commit to trigger automatic build, OR                      │
│ 2. Manually trigger build in Amplify Console                           │
│ 3. SSM parameters are loaded during build phase                        │
│ 4. Warning should disappear once parameters are detected               │
└─────────────────────────────────────────────────────────────────────────┘
